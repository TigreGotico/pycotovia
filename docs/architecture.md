# Architecture

pycotovia replicates the Cotovia G2P pipeline in pure Python. The pipeline is:

```
Input text
    ↓
Tokenize (whitespace, letters only)
    ↓
For each word:
    Exception preprocessing (trata_excepcions_xe, trata_excepcions_w)
    ↓
    Syllabify (silabify)
    ↓
    Assign stress (acentuar_prosodicamente)
    ↓
    Timbre (open/closed e/o) — skipped in transcription mode
    ↓
Join into phrase: "## word1 word2 ##"
    ↓
Apply G2P rewrite rules (transcripcion)
    ↓
Strip markers (#, %, ^, -) per output level
    ↓
Phoneme string
```

## Module map

| Module | C counterpart | Purpose |
|--------|---------------|---------|
| `phonemize.py` | `transcripcion.cpp` | Orchestrator: tokenize → preprocess → rules → strip |
| `syllabify.py` | `sil_acen.cpp` (`kkseparar_silabas`) | Syllabification |
| `stress.py` | `sil_acen.cpp` (`acentuar_prosodicamente`) | Prosodic stress placement |
| `engine.py` | `transcripcion.cpp` (`transcribe`) | Rule-matching engine (longest-match first) |
| `rules_data.py` | `alof_gal.hpp` / `alof_cas.hpp` | Generated G2P rewrite rules |
| `exceptions.py` | `trat_fon.cpp` | Exception word lists (x→ks, w→gu, etc.) |
| `phonemes.py` | `fonemas.cpp` | Phoneme inventory + Cotovia→IPA mapping |
| `charset.py` | `letras.hpp` | Latin-1 character classification |
| `timbre.py` | `prosodia.cpp` | Open/closed e/o timbre (not used in -t mode) |
| `cli.py` | `main.cpp` | Command-line interface |

## Rule generation

`rules_data.py` is generated by `extract_rules.py` from the Cotovia C++ header files (`alof_gal.hpp`, `alof_cas.hpp`). It produces a dict mapping first-character ordinals to lists of `(antecedent, consume, consequent)` tuples sorted by decreasing antecedent length. This is the exact structure the C engine uses.

## Language support

Two independent rule sets are generated:

- `GALEGO_RULES_SV` — Galician with semivowel rules
- `CASTELLANO_RULES_SV` — Spanish with semivowel rules

Both are selected at runtime by `Phonemizer(lang=...)`. The `exceptions.py` module also branches on `lang` for language-specific exception lists (e.g. Spanish `x` → `ks`, Galician `x` → `S`).
